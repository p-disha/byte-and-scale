Style guide

Living component reference. Every component here pulls its values from design-system/tokens.css — see design-system/style-guide.md for the numbered rules behind each token.

Traceability example

The pass condition this page exists to satisfy: pick one component and trace its values back through a token to a specific style-guide rule, with no gaps.

1. Component — .card-course in design-system/components.css:

  box-shadow: var(--shadow-block);

↓

2. Token — design-system/tokens.css:

  --shadow-block: .35rem .35rem 0 var(--color-ink);

↓

3. Style-guide rule — design-system/style-guide.md, SHADOW-2:

  "Course/module cards use --shadow-block, not --shadow-soft — the same hard offset shape as educative.io's module-tile shadow."

↓

4. Reference evidence — references/NOTES.md, educative.io section:

  box-shadow:0 0 .25rem rgba(0,0,0,.15),.5rem .5rem 0 #172963 — grepped live from educative.io's production CSS.
